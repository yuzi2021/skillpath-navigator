RESTful API Endpoints

  • GET /api/skills/most-demanded/

    Returns the top 20 most demanded skills across all entry-level job postings, ranked by number of jobs requiring each skill. Helps bootcamp graduates prioritize what to learn first.

  • GET /api/skills/for-role/

    Retrieves skills commonly required for a specific entry-level role type (e.g., backend, frontend, full-stack, data analyst). Shows what skills are most important for breaking into each role.
    Query params: role (required)

  • GET /api/jobs/by-skills/

    Finds entry-level jobs matching user's current skills. Returns jobs with match scores showing what percentage of required skills the user already has. Helps identify which positions you're ready to apply for.
    Query params: skills (comma-separated list)

  • GET /api/skills/combinations/

    Analyzes which skills are commonly required together in entry-level jobs. For a given skill (e.g., Python), shows which other skills employers typically look for in the same position. Helps plan complementary skill development.
    Query params: skill (required)

  • GET POST /api/bookmarks/

    GET: List all bookmarked jobs with application tracking status and statistics.
    POST: Create new bookmark for a job of interest. Receives personalized similar job recommendations based on skill overlap.
    POST Body: {"job_link": "https://...", "notes": "...", "status": "interested"}

  • GET PUT PATCH DELETE /api/bookmarks/{id}/

    Complete CRUD operations for individual bookmarks:
    GET: Retrieve full bookmark details with job information
    PUT/PATCH: Update bookmark notes or status (interested → applied → interviewing)
    DELETE: Remove bookmark from saved jobs
    Demonstrates CREATE, UPDATE, DELETE operations required by assignment.

Setup Instructions

Follow these steps to deploy the application:

  1. Create virtual environment: python -m venv venv
  2. Activate venv: venv\Scripts\activate (Windows) or source venv/bin/activate (Mac/Linux)
  3. Install dependencies: pip install -r requirements.txt
  4. Run migrations: python manage.py migrate
  5. Load data: python manage.py load_data
  6. Create superuser (optional): python manage.py createsuperuser
  7. Run server: python manage.py runserver
  8. Run tests: python manage.py test

Note: Data loading may take 1-2 minutes. The load_data command uses bulk operations for optimal performance.
